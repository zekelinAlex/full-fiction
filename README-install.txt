Full Fiction
============

Мод для Split Fiction (Steam): в онлайн-кооперативе каждый видит
свой экран целиком, без разделения пополам.

УСТАНОВКА
1. Закрой игру.
2. Запусти FullFiction-Setup.exe.
   Если Windows покажет синее окно "Windows защитила ваш компьютер",
   нажми "Подробнее" -> "Выполнить в любом случае". Это нормально
   для программ без платной цифровой подписи.
3. Если хочешь, поставь галочку "Автоматический режим" (см. ниже).
4. Нажми "Установить". Игра находится автоматически, если нет -
   нажми "Выбрать папку игры..." и укажи папку Split Fiction.
5. Запускай игру из Steam как обычно.

В ИГРЕ
F10 переключает режим по кругу:
  раздельный экран -> твой персонаж на весь экран -> персонаж напарника
Во время катсцен игра показывает всё как задумано.

РУЧНОЙ И АВТОМАТИЧЕСКИЙ РЕЖИМ
- Ручной (по умолчанию): после катсцен и загрузок остаётся обычный
  раздельный экран, полный экран включаешь сам клавишей F10.
- Автоматический: после катсцен и загрузок мод сам включает полный
  экран твоего персонажа. Удобнее, но менее стабильно: в редких
  местах игра может показать не то, что задумано - тогда жми F10.
Режим можно поменять в любой момент: запусти установщик и щёлкни
галочку, он сохранится сразу и включится при следующем запуске игры.

Напарнику мод ставить не обязательно: каждый ставит его себе сам,
если хочет полный экран у себя.

УДАЛЕНИЕ
Запусти FullFiction-Setup.exe и нажми "Удалить мод".
Или в Steam: Свойства игры -> Установленные файлы -> Проверить
целостность файлов.

Если антивирус ругается на dwmapi.dll - это ложное срабатывание:
так работает UE4SS, загрузчик модов для игр на Unreal Engine.
