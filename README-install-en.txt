Full Fiction
============

A mod for Split Fiction (Steam): in online co-op each player sees
their own view fullscreen instead of half the screen.

INSTALL
1. Close the game.
2. Run FullFiction-Setup.exe.
   If Windows shows a blue "Windows protected your PC" window,
   click "More info" -> "Run anyway". This is normal for programs
   without a paid code signing certificate.
3. Optionally tick "Auto mode" (see below).
4. Click "Install". The game is found automatically; if not,
   click "Choose game folder..." and pick the Split Fiction folder.
5. Launch the game from Steam as usual.

IN GAME
F10 cycles the view:
  split screen -> your character fullscreen -> your partner's character
Cutscenes are always shown the way the game intends.

MANUAL AND AUTO MODE
- Manual (default): after cutscenes and loading screens you keep the
  regular split screen and switch to fullscreen yourself with F10.
- Auto: after cutscenes and loading screens the mod switches to your
  character's fullscreen view by itself. More convenient but less
  stable: in rare spots the game may show something other than
  intended, press F10 then.
You can change the mode at any time: run the installer and click the
checkbox. It is saved instantly and applies on the next game launch.

Your partner does not need the mod: everyone installs it for
themselves if they want fullscreen on their side.

UNINSTALL
Run FullFiction-Setup.exe and click "Uninstall".
Or in Steam: game Properties -> Installed Files -> Verify integrity
of game files.

If your antivirus flags dwmapi.dll, it's a false positive: this is
how UE4SS, the mod loader for Unreal Engine games, works.
